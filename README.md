# Граф денег — Hackalem

Одна команда превращает три Parquet в проверенные CSV: роли клиентов, связные
кластеры и приоритет изучения сети. Роли — объяснимые гипотезы по наблюдаемым
переводам, а не подтверждение правонарушения.

## Запуск

Команды выполняются **из корня проекта**. Нужен CPython **3.14**;
`.python-version` сам Python не устанавливает.

```bash
python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m hackalem --data data --out out
```

В `data/` должны находиться `nodes.parquet`, `edges.parquet` и
`transactions.parquet`. Для нового результата путь `out` должен отсутствовать;
ранее опубликованный этой программой комплект можно обновлять.

## Результат

| Файл в `out/` | Содержание |
|---|---|
| `nodes_roles.csv` | Все клиенты, роли, признаки, оценки и объяснения |
| `clusters.csv` | Размеры, обороты и гипотезы кластеров |
| `top_nodes.csv` | Топ-20 с основаниями приоритета |
| `graph.json` | Граф и признаки; идентификаторы сохранены строками |
| `manifest.json` | Конфигурация и SHA-256 входов и результатов |

На текущих данных: **2 248 клиентов, 89 связных кластеров, 20 строк топа**.
Новый комплект проверяется целиком и публикуется атомарно; при ошибке предыдущая
версия сохраняется. Вход и выход не должны пересекаться.

Проверка результата и перенос в обычную папку без ссылок:

```bash
.venv/bin/python -m hackalem validate --data data --out out
.venv/bin/python -m hackalem export --source out --destination reports/portable-result
```

## Структура

```text
hackalem/             программа и точка входа python -m hackalem
tests/                проверки алгоритмов, контрактов и хранения
data/                 три исходных Parquet
docs/                 методика, разработка и результаты экспериментов
experiments/          скрипты аудита и сравнения; results/ — исторические JSON
starter/starter.py    совместимая прежняя точка входа
```

`out/`, версии результатов, локальные окружения и новые отчёты в `reports/`
не входят в исходный код.
